## Ejecutar en Windows
1. Extraiga el ZIP. No ejecute los archivos dentro del archivo comprimido.
2. Abra IDLE (Python 3), seleccione File > Open y abra, por ejemplo, solucion1.py.
3. Presione F5 (Run > Run Module). Escriba las respuestas en la ventana Shell y pulse Enter.
4. Repita con cada programa. Los decimales se escriben con punto: 125.50.

También puede abrir una terminal en esta carpeta y ejecutar:

```console
py solucion1.py
```

Si no tiene Python, primero necesita un intérprete de Python 3 para ejecutar los archivos.

## Decisiones ante ambigüedades de la guía
- Solución 1: se sigue literalmente «menor a»: [0,100) = 5%; [100,200) = 10%; [200,500) = 15%; [500,800) = 20%; desde 800 = 25%. Los textos entre paréntesis de la guía contradicen estos límites. Conviene confirmar esta interpretación con el docente antes de entregar.
- Solución 3: límites de horario incluidos: 7 a 18 para estudiantes, 6 a 21 para instructores. Hora decimal: 7.5 equivale a 7:30; 18.5 equivale a 18:30. La alerta impide cualquier ingreso.
- Soluciones 6 y 9: tablas de 1 a 10 y de 10 a 1, respectivamente; la guía no fija su extensión.
- Solución 10: incluye vocales con tilde y ü, tanto mayúsculas como minúsculas.
- Solución 14: se conserva «Python» y muestra una breve descripción. Resta y Multiplicación piden dos números. Se agrega la opción 4, Salir. Si el docente confirma que «Python» debía decir «Suma», será necesario ajustar esa opción.
- Soluciones 18 y 19: números enteros no negativos; no se usa representación de negativos ni fracciones.
- En los textos se cuentan espacios y signos. La solución 4 distingue mayúsculas de minúsculas.
- Si se escribe texto donde se pide un número, se informa el error y se debe volver a ejecutar el programa.
